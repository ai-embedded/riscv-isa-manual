# RISC-V Instruction Set Manual

This repository contains the source files for the official RISC-V Instruction Set Manual, which consists of two main volumes:

- **Volume I**: User-Level ISA (Unprivileged Architecture)
- **Volume II**: Privileged Architecture

## Key Features

- **Bilingual Documentation**: Full support for both English and Chinese versions
- **Multiple Output Formats**: PDF, HTML, and EPUB generation
- **Technical Specification**: Comprehensive ISA documentation with detailed instruction formats, register definitions, and architectural specifications
- **Open Source**: Licensed under Creative Commons Attribution 4.0 International License

## Target Audience

- Computer architecture researchers and educators
- Hardware implementers and chip designers
- Software developers working with RISC-V
- Students learning computer architecture

## Documentation Structure

The manual is organized into detailed chapters covering base instruction sets, standard extensions, privileged architecture, memory models, and various specialized extensions like vector processing, cryptography, and floating-point operations.
