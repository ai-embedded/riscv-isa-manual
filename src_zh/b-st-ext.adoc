[[bits]]
== "B" 位操作扩展，版本 1.0.0

B 标准扩展包含由 Zba、Zbb 和 Zbs 扩展提供的指令。

[[preface]]
=== Zb* 概述

位操作（bitmanip）扩展集合由若干个组件扩展组成，这些扩展针对基础 RISC-V 架构，旨在提供代码大小减少、性能提升和能耗降低的某种组合。
虽然这些指令设计为通用目的，但某些指令在某些领域比其他领域更有用。
因此，提供了几个较小的 bitmanip 扩展。每个较小的扩展按照通用功能和用例进行分组，并且每个扩展都有自己的 Zb* 扩展名称。

每个 bitmanip 扩展包含一组具有相似目的的 bitmanip 指令，这些指令通常可以共享相同的逻辑。一些指令仅在一个扩展中可用，而其他指令在多个扩展中可用。
这些指令具有独立于它们所出现的扩展的助记符和编码。
因此，在实现具有重叠指令的扩展时，在逻辑或编码方面没有冗余。

bitmanip 扩展为 RV32 和 RV64 定义。

=== Word 指令

bitmanip 扩展遵循 RV64 中的约定，即带有 _w_ 后缀的指令（在 _w_ 之前没有点）忽略其输入的高 32 位，将最低有效 32 位作为有符号值进行操作，并产生一个符号扩展到 XLEN 的 32 位有符号结果。

带有后缀 _.uw_ 的 Bitmanip 指令有一个操作数，该操作数是从指定寄存器的最低有效 32 位提取的无符号 32 位值。除此之外，这些指令执行完整的 XLEN 操作。

带有后缀 _.b_、_.h_ 和 _.w_ 的 Bitmanip 指令仅查看输入的最低有效 8 位、16 位和 32 位（分别），并产生一个根据具体指令符号扩展或零扩展的 XLEN 宽度结果。

=== 指令语义的伪代码

<<#insns-b>> 中每个指令的语义使用类似 SAIL 的语法表达。

[#zba,reftext=地址生成指令]
==== Zba: 地址生成

Zba 指令可用于加速生成索引到基本类型数组（半字、字、双字）的地址，使用无符号字大小和 XLEN 大小的索引：将移位的索引添加到基地址。

移位和加法指令执行 1、2 或 3 位的左移，因为这些在实际代码中很常见，并且因为它们可以用超出简单加法器的最少额外硬件来实现。这避免了在实现中延长关键路径。

这些指令的形式是：

.Zba 指令
[%header,cols="^1,^1,4,8"]
|===
|RV32 |RV64 |助记符 |指令

| &#10003; | &#10003; |sh1add _rd_, _rs1_, _rs2_ |<<#insns-sh1add>>
| &#10003; | &#10003; |sh2add _rd_, _rs1_, _rs2_ |<<#insns-sh2add>>
| &#10003; | &#10003; |sh3add _rd_, _rs1_, _rs2_ |<<#insns-sh3add>>
|          | &#10003; |add.uw _rd_, _rs1_, _rs2_ |<<#insns-add_uw>>
|          | &#10003; |sh1add.uw _rd_, _rs1_, _rs2_ |<<#insns-sh1add_uw>>

|          | &#10003; |sh3add.uw _rd_, _rs1_, _rs2_ |<<#insns-sh3add_uw>>
|          | &#10003; |slli.uw _rd_, _rs1_, _imm_ |<<#insns-slli_uw>>
|===

===== OR 组合

*orc.b* 将结果 _rd_ 中每个字节的位设置为全零（如果 _rs_ 相应字节内没有位被设置），或设置为全一（如果 _rs_ 相应字节内有任何位被设置）。

一个用例是字符串处理函数，如 *strlen* 和 *strcpy*，它们可以使用 *orc.b* 通过计算字中前导非零字节的设置位来测试终止零字节。
